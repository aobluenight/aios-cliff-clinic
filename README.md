# 悬崖医馆 Cliff Clinic

在峭壁上一层层钉木板、开医馆的生存经营游戏。从一间破木屋起家，一路盖到七层悬崖圣馆；病人来了看病抓药赚铜钱，风雨夜塌楼药毁人亡。单文件 HTML，零依赖，打开即玩。

## 在线游玩

GitHub Pages 上线后此处填链接（本仓 `/index.html` 直玩，手机可点）。

## 平衡数据（随机机器人 ×200 / 贪心机器人 ×200）

| 机器人 | 胜率 | 中位结局 |
|---|---|---|
| 随机决策 | 2/200（1%） | 第 7 天殁 |
| 贪心决策 | 157/200（78.5%） | 第 80 天通关 |

复现：`node _冒烟_随机.js` / `node _冒烟_贪心.js`（需 Node ≥ 18）。

## 本地游玩

下载仓库后双击 `index.html` 即可（Chrome/Edge/Firefox 均可）。

## 已知坑

- Windows 下若用某些工具转存为 GBK 编码会花中文渲染——保持 UTF-8 原件即可。
- 纯手写 SVG 崖壁剖面，无任何外部资产/CDN，断网可玩。
